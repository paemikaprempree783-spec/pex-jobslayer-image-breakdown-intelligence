# Pex JobSlayer Experiment Schema

Use one record per creative direction. This schema prioritizes the business question and the originality boundary over a visual inventory.

| Field | Notes |
|---|---|
| direction_id | Stable label such as A, B, or C |
| business_outcome | attention, click, lead, purchase, trust, education, memory |
| source_principle | Abstract communication principle only |
| do_not_copy | Wording, layout, palette, scene, prop, or distinctive treatment excluded |
| new_device | New demonstration, comparison, context, metaphor, or information structure |
| changed_dimensions | At least three major dimensions |
| product_truth | Verified facts that must remain true |
| hypothesis | Behavior expected to change |
| control | Existing or baseline execution |
| primary_metric | Main learning metric |
| guardrail | Quality, policy, or business protection metric |
| read_rule | Decision rule after the observation window |
| risk | Main reason the direction could fail |
| evidence_needed | Missing data or user input |
